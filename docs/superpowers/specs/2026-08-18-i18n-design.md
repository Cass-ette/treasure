# 多语言支持（i18n）设计文档

**日期**：2026-08-18
**状态**：已批准，待实现
**作者**：Cass-ette

## 背景

项目所有 UI 文案硬编码中文（16 个模板 / 2162 行、6 个 JS 文件、44 处 flash 消息），无任何 i18n 基础设施。用户未来可能出国、可能玩美股，需要：

1. 中英双语界面
2. 颜色习惯随语言切换（zh→红涨绿跌，en→绿涨红跌），保留手动覆盖
3. 架构留出扩展位（未来加语言只需新增翻译文件）

项目已有基础：`base.html` 的 `data-color-mode` 属性 + localStorage 持久化 + dashboard 手动切换按钮。可复用。

## 关键决策

| 维度 | 选择 | 理由 |
|---|---|---|
| 方案 | Flask-Babel 管模板+Python；启动时 .mo 导出 JSON 注入 JS | 单一真相源；无 JS 提取器构建负担 |
| 目标语言 | 中英双语 | 需求范围；架构支持后续扩展 |
| msgid | **中文原文** | 源码可读；翻译缺失降级显示中文 |
| 默认语言 | session → localStorage → Accept-Language | 用户选择优先，浏览器兜底 |
| JS 文案 | 后端注入 `window.I18N`，`t('中文键')` 取值 | 不依赖 Babel JS 提取 |
| 颜色模式 | 跟随语言（zh→cn / en→intl）+ 手动覆盖 | 复用现有 data-color-mode |
| 切换入口 | 导航栏下拉（语言 + 颜色模式都收进来） | 全局可见；移除 dashboard 按钮避免双控 |
| 市场适配 | **明确排除**（YAGNI） | 美股指标差异是 market 层问题，与语言正交 |

## 语言探测

```
1. session['locale']          本次会话选过 → 直接用
2. localStorage.locale        以前选过（session 过期）→ JS 首次跳 /locale/set 写 session
3. Accept-Language 头         en* → en，其余 → zh
```

## 切换接口

```python
@bp.route('/locale/set', methods=['POST'])
def set_locale():
    lang = request.form.get('lang')  # 'zh' | 'en'
    session['locale'] = lang
    return jsonify(ok=True)
# 前端：POST 后 location.reload()
```

POST 防误触/预加载。前端同时写 localStorage 供 session 过期后恢复。

## 颜色模式三态

```
跟随语言（默认）: locale=zh → data-color-mode="cn"；locale=en → "intl"
手动 cn / intl   : localStorage 存 override 标记，切语言不再联动
```

现有 dashboard.js 的切换按钮移除，功能收进导航栏下拉。

## JS 字典注入

```html
<script>window.I18N = {{ js_translations()|tojson }};</script>
```

`js_translations()`：当前 locale 从 .mo 读全部 msgid → `{msgid: msgstr}`。

```js
var t = window.I18N || function(k){ return k; };
t('数据加载失败')  // zh: 原样；en: 'Data loading failed'
```

要点：
- 兜底返回原中文，缺键不炸
- 动态拼接拆开：`t('现价') + ' ' + price.toFixed(3)`
- JS 键必须与 .po msgid 逐字一致；用测试抽查关键键

## 翻译文件与构建

```bash
pybabel extract -F babel.cfg -o app/translations/messages.pot .
pybabel update -i messages.pot -d app/translations
# 填 en 翻译（可 AI 批量）
pybabel compile -d app/translations
```

requirements.txt 新增：`Flask-Babel`、`babel`。

## 覆盖范围

**翻**：模板静态文案、Python flash（44 处）、JS 动态文案（75 行）、日期格式（Babel format_date）。

**不翻**：DB 数据（基金名/用户名/备注/OCR 内容）、服务端日志。

**语言与内容解耦**：切语言只换 UI 壳；美股市场适配（涨跌停/盘前盘后等）不在本次范围。

## 风险与缓解

| 风险 | 缓解 |
|---|---|
| JS 键与 .po 不一致 → 静默回退中文 | 迁移时 grep 提取 JS 中文串统一进 .po；测试抽查 |
| 忘记跑 pybabel compile → 翻译不生效 | 开发期自动 compile（debug 模式启动时检查 .mo 时间戳）；CI 加检查 |
| 文案遗漏（某处还是中文） | grep 扫描模板残留中文字面量，迁移完成后跑一遍清零 |
