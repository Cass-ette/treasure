# 股票筛选

`/stocks/screener` 使用东方财富公开的股票列表快照，当前支持沪深全市场、沪市、深市、沪深主板、创业板和科创板。筛选条件在服务端本地执行，包含：

- 代码或名称关键词
- 价格、涨跌幅、换手率
- 成交额（页面单位：万元）
- 动态 PE、PB
- 总市值（页面单位：亿元）
- 排除 `ST` 和退市整理股票、排序和升降序

快照最多每 5 分钟刷新一次。接口失败时只会显示本进程内最近的缓存，并标记“使用缓存快照”；没有成功快照则返回错误，不会把缺失字段当作 0。行情接口可能有延迟，筛选结果只用于研究整理，不构成投资建议。

当前版本是快照筛选，不会逐只请求历史 K 线，因此没有宣称“均线突破”“RSI”或财务增长率等历史/基本面条件。后续增加这些条件时，应先建立统一的历史数据缓存和数据日期标识，避免把不同交易日的数据混在一起。
